# Mitwirken

Beiträge sind willkommen. Änderungen sollten in `src/index.html` erfolgen; generierte HTML-Dateien werden nicht direkt bearbeitet.

Vor einer Übergabe oder einem Pull Request:

```bash
npm run check
```

Produktänderungen benötigen einen Changelog-Eintrag und synchronisierte Release-Metadaten. Eine visuelle Prüfung im Browser bleibt bei Layout- oder Interaktionsänderungen zusätzlich erforderlich.

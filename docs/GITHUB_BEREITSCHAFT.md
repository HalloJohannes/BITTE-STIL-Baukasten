# GitHub-Bereitschaft

## Vorbereitet

- MIT-Lizenz und sichtbarer Lizenzlink
- README, Beitrags- und Sicherheitshinweise
- reproduzierbarer, abhängigkeitsfreier Build
- zentraler Prüflauf
- GitHub-Actions-Workflow
- repository-lokaler Codex-Marketplace und validierbares Plugin
- Trennung von Quelle, Release, Historie und lokalem Arbeitsmaterial
- GitHub-Pages-Workflow mit getrenntem, minimalem Veröffentlichungsartefakt

## Vor der öffentlichen Veröffentlichung

- finale Browser-Sichtprüfung dokumentieren
- erste Release-Notiz aus dem Changelog erstellen

Ziel-Repository: `HalloJohannes/BITTE-STIL-Baukasten` (öffentlich).
Geplante Pages-Adresse: `https://hallojohannes.github.io/BITTE-STIL-Baukasten/`.

Die Anwendung überträgt im Betrieb keine Daten. Die zwei externen Links (LinkedIn, MIT-Lizenz) werden nur nach einem bewussten Klick geöffnet.
